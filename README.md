# java-racingcar-precourse
우아한테크코스 웹 백엔드 프리코스 2주차 과제: 자동차 경주
___

## 📝 구현 기능 목록

### 1. 경기 설정
  - [ ] **경주할 자동차 이름 설정**
    - 입력 안내 문구 출력 (형식: `경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)`)
    - 자동차 이름 입력
    - **(예외 처리)** 자동차 이름 유효성 검사: `IllegalArgumentException`
      - 이름이 5자를 초과한 경우
      - 이름이 빈 문자열인 경우
      - 이름이 공백 문자로만 이루어져있는 경우
      - 동일한 이름의 자동차가 2대 이상인 경우
    - **(예외 처리)** 자동차 수 유효성 검사: `IllegalArgumentException`
      - 경주할 자동차의 수가 1대 이하인 경우
  - [ ] **시도할 횟수 설정**
    - 입력 안내 문구 출력 (형식: `시도할 횟수는 몇 회인가요?`)
    - 시도 횟수 입력
    - **(예외 처리)** 시도 횟수 유효성 검사: `IllegalArgumentException`
      - 시도 횟수를 숫자로 변환 불가한 경우
      - 시도 횟수가 0회 이하인 경우

### 2. 경기 실행
  - [ ] **차수별로 자동차 이동**
    - 자동차별 전진 여부 결정 (전진 조건: `0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우`)
    - 각 자동차 이동 거리 조정
  - [ ] **실행 결과 출력**
    - 첫줄에 실행 결과 안내 문구 출력 (형식: `실행 결과`)
    - 차수별 실행 결과 출력
      - 각 자동차의 이름과 이동 거리를 "-" 문자로 시각화하여 출력 (형식: `[자동차 이름] : [이동 거리 (1회당 -로 표시)]`)

### 3. 경기 종료
  - [ ] **최종 우승자 선정**
    - 우승자 선별 기준 설정: 최대 이동 거리 파악
    - 우승자 숫자 및 이름 파악
    - 최종 우승자 안내 문구 출력 (형식: `최종 우승자 : [우승한 자동차 이름 (여러 명일 경우 쉼표로 구분)]`)
___

## 🗂️ 클래스 구조 (MVC 패턴 기반)

### Controller
- `RacingGameController`: 전체 프로그램의 **흐름 제어** (경기 설정 → 경기 실행 → 경기 종료)

### View
- `InputView`: 경기 설정 **입력**
- `OutputView`: 차수별 경기 결과, 최종 우승자 **출력**

### Model
- **Service**
  - `ConfigService`: 경기 설정 관련 로직
  - `RaceService`: 경기 실행 관련 로직 (라운드 진행, 최종 우승자 선출 등)
- **Domain**
  - `Car`: 자동차 이름 유효성 검사, 자동차 이동
  - `RaceConfiguration`: 자동차 수, 자동차 이름 중복 여부, 경기 시도 횟수 유효성 검사
  - `ErrorMessage`: 예외 메시지 관리
